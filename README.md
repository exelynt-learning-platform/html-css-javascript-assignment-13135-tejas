
# TechNova 2026 - College Tech Fest

## Overview

TechNova 2026 is a simple college technology fest webpage
built using HTML, CSS, and JavaScript.

The page introduces the fest, displays event dates and venues,
and presents three featured events with their timings.

## Features

- Fest name and introduction
- Event dates and venue details
- Registration form link
- Three event cards using CSS Flexbox
- Interactive show/hide schedule button
- Responsive layout for smaller screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Setup Instructions

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser.

No additional packages or installations are required.

## How the Button Works

The schedule button uses JavaScript's addEventListener()
to respond to clicks.

The classList.toggle() method adds or removes the
hidden CSS class to show or hide the schedule section.
